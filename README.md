# 小星星桌面宠物

本项目包含两种使用方式：

## 方式一：Codex 桌面宠物（原版）

把 `starlet/` 目录下的两个文件放到 `C:\Users\你的用户\.codex\pets` 目录下就可以了。
找不到目录可以打开 Codex 客户端，设置——外观——自定义宠物——打开文件夹。

## 方式二：独立桌面宠物应用（推荐）

新增独立 Electron 桌面宠物应用，包含以下功能：

1. **喝水提醒** - 每30分钟提醒喝水，可自定义间隔
2. **文件回收站** - 拖拽文件到宠物嘴巴即可删除
3. **专注模式** - 显示敲键盘动画，带计时器
4. **聊天同步** - 与小程序聊天实时同步

详见 `desktop-pet/README.md`
